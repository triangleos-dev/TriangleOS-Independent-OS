# TriangleOS
An independent x86-64 operating system built from the ground up.
TriangleOS is an experimental operating system built from the ground up.

It is not based on the Linux kernel or intended to be a Linux/Unix distribution.

## Goals
x86-64 only- Independent kernel- Independent boot process- Own hardware and system interfaces- Own filesystem- Own package manager and repository- Lightweight and performant- Designed for both older and modern x86-64 hardware- Eventually provide a native graphical environment

## Current Status
🚧 Early development TriangleOS is currently in the planning and initial development stage.
The first milestone is a bootable x86-64 system capable of initializing its kernel and displaying basic output.
